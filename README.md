# ClipRing

Удерживайте **Win** — вокруг курсора появится кольцо с буфером обмена. Наведите на нужный элемент
(достаточно сдвинуть мышь в его сторону) и отпустите Win — он вставится туда, где стоит курсор ввода.

- **Esc** при открытом кольце — закрыть без вставки; курсор в центре при отпускании — тоже ничего не вставится.
- Короткое нажатие Win по-прежнему открывает «Пуск», сочетания Win+E, Win+V и др. работают как обычно.
- **Свои слова** (почта, частые фразы) добавляются в настройках и видны в кольце всегда, со звёздочкой.
- Иконка в трее: правый клик — «Включено» / «Настройки…» / «Выход», двойной клик — настройки.

История буфера хранится только в памяти (последние 50 текстов) и пропадает при выходе.
Содержимое, которое менеджеры паролей помечают как «не сохранять в историю», не запоминается.
Настройки лежат в `%APPDATA%\ClipRing\config.json`.

## Сборка

Нужен Rust (тулчейн `x86_64-pc-windows-gnu` или `-msvc`):

```
cargo build --release
```

Готовый файл: `target\release\clipring.exe` — его можно скопировать куда угодно и запускать без установки.

## Ограничения

- Вставка делается через буфер обмена и Ctrl+V: после вставки в буфере остаётся выбранный элемент.
- В окна, запущенные от имени администратора, Windows не даёт вставлять из обычной программы —
  для них ClipRing тоже нужно запускать от администратора.
- Только текст: картинки и файлы в кольцо не попадают.
