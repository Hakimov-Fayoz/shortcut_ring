# Shortcut Ring — WinHoldMenu

Утилита для Windows: зажмите **Win** — рядом с курсором появляется меню с историей буфера
обмена, своими заготовками текста и открытыми окнами. Наведите на пункт — текст вставится
туда, где стоит курсор ввода, или выбранное окно выйдет на передний план.

Короткое нажатие Win по-прежнему открывает «Пуск», а сочетания Win+E, Win+V и т. д.
работают как обычно.

> **Статус:** C#-версия в разработке. Готовы перехват клавиатуры, синтетический ввод,
> настройки и хранилище истории; окно меню, трей и автозапуск ещё не перенесены.
> Рабочая Rust-версия — в ветке [`rust`](../../tree/rust).

## Стек

- .NET 8, C# (latest), WinUI 3 / Windows App SDK 1.8
- Unpackaged + self-contained: на выходе переносимая папка, установка не нужна
- Windows 10 1809+ (x64, ARM64)

## Как это работает

`WinKeyHook` — конечный автомат поверх `WH_KEYBOARD_LL`:

| Состояние | Что происходит |
|-----------|----------------|
| `Idle`    | ждём нажатия Win |
| `Pending` | Win нажат, тикает таймер `holdMs`. Любая другая клавиша — это обычное сочетание, отпускаем |
| `Menu`    | таймер сработал: инжектим неназначенную клавишу `0xE8`, чтобы при отпускании Win не открылся «Пуск», и показываем меню |
| `Done`    | действие выполнено / жест отменён — ждём физического отпускания Win |

Перед вставкой Win «отпускается» виртуально (`BeginAction`), иначе целевое приложение
увидит Win+Ctrl+V. Все синтетические события помечаются `dwExtraInfo = Marker`,
чтобы собственный хук их игнорировал.

## Сборка

Нужны Windows, .NET 8 SDK и Visual Studio 2022 с нагрузкой
**Windows application development** (или только .NET SDK для сборки из командной строки).

```powershell
.\build.ps1                     # win-x64 → artifacts\win-x64\WinHoldMenu.exe
.\build.ps1 -Runtime win-arm64
```

Или откройте `WinHoldMenu.sln` в Visual Studio и выберите платформу x64 / ARM64.

## Настройки

При первом запуске рядом с exe создаётся `settings.json`:

```json
{
  "holdMs": 150,
  "trigger": "hover",
  "hoverDwellMs": 180,
  "historySize": 5,
  "maxWindows": 8,
  "pinned": ["Здравствуйте!", "Спасибо, с уважением", "me@example.com"]
}
```

| Ключ | Значение | Диапазон |
|------|----------|----------|
| `holdMs` | сколько держать Win до появления меню, мс | 50–2000 |
| `trigger` | `hover` — действие по наведению, `release` — по отпусканию Win | |
| `hoverDwellMs` | задержка наведения в режиме `hover`, мс | 0–2000 |
| `historySize` | сколько последних текстов из буфера показывать | 1–10 |
| `maxWindows` | сколько окон показывать | 1–12 |
| `pinned` | свои заготовки, показываются первыми | до 5 |

Битый файл молча заменяется значениями по умолчанию; поддерживаются комментарии и
висячие запятые.

## Ограничения

- Вставка в окна, запущенные от администратора, работает только если утилита тоже запущена
  от администратора (UIPI).
- Только текст: картинки и файлы в историю не попадают.
